# tools/punctuate.py — пунктуация окнами через claude, сверка слов и предложения с таймкодами

**Зависит от:** 180

**Правит:** tools/punctuate.py 

## Цель

Должен появиться инструмент tools/punctuate.py, который берёт transcript.json (схема transcript/1) и строит из него файл punctuated.json схемы punctuated/1: текст с расставленной claude пунктуацией, заглавными и абзацами, разбитый на предложения, у каждого предложения — таймкод начала и конца из пословных таймкодов транскрипта. Текст отправляется в claude окнами по ~100 сегментов; после каждого ответа последовательность слов сверяется с исходной, и если она не совпала, окно откатывается к дословному тексту модели без пунктуации и помечается в файле, а код возврата инструмента становится ненулевым.

## Критерии приёмки

- [ ] `python tools/punctuate.py --selftest` проходит без установленного claude и без весов моделей; проверки идут на подставном claude (скрипт-заглушка на PATH) и покрывают: успешное окно, окно с изменённым словом (откат), окно с выдуманными добавленными словами (откат), полное отсутствие claude (все окна в откате, код 1), разбиение на предложения, монотонность таймкодов, запись и перечитывание punctuated.json
- [ ] Флаги: `--transcript <путь>` (обязателен), `--out <путь>` (обязателен), `--window <число сегментов>` (по умолчанию 100), `--timeout <сек>`, `--attempts <число>`, `--log-dir <каталог>`, `--selftest`, `-h/--help` со справкой на русском
- [ ] Окна формируются по порядку сегментов, без перекрытия, по --window сегментов; склейка результатов строго в порядке окон; в промпт окна добавляется последнее предложение предыдущего окна как контекст с явной пометкой «не выводить»
- [ ] Промпт по-русски и явно запрещает: менять, добавлять и удалять слова, переводить числа в цифры и наоборот, исправлять оговорки, переставлять слова, дописывать комментарии; разрешены только знаки пунктуации, регистр букв и разбиение на абзацы пустой строкой; ответ — только текст
- [ ] Сверка слов: обе последовательности нормализуются (нижний регистр, ё→е, выкидываются все символы кроме букв и цифр, пустые токены отбрасываются) и сравниваются поэлементно; при расхождении в stderr печатается номер окна, позиция первого расхождения и пара «было → стало»
- [ ] При расхождении (или при ошибке claude по этому окну) окно целиком заполняется дословным текстом сегментов без пунктуации, в punctuated.json окно получает `status: "fallback"` и `reason`, а предложения этого окна — `fallback: true`; остальные окна обрабатываются как обычно
- [ ] Таймкоды предложений считаются от начала записи: start первого слова предложения и end последнего; при отсутствии пословных таймкодов у сегмента берутся границы сегмента; таймкоды предложений не убывают, лежат внутри [0, source_duration] и внутри границ своих сегментов
- [ ] Файл на выходе — JSON схемы `punctuated/1` ровно с полями: `schema`, `source`, `source_duration`, `transcript`, `model`, `windows` (список `{index, segments: [первый, последний], status: "ok"|"fallback", reason}`), `paragraphs` (список `{index, window, sentences: [первый, последний]}`), `sentences` (список `{index, start, end, text, window, fallback}`), `text` (весь текст, абзацы разделены пустой строкой), `stats` (`{windows, fallback_windows, paragraphs, sentences, words}`); числа округлены до 3 знаков, JSON пишется с ensure_ascii=False и отступом 2
- [ ] Коды возврата: 0 — все окна прошли сверку; 1 — есть окна в откате или claude был недоступен (файл всё равно записан и валиден); 2 — вход непригоден (нет файла, не та схема, нет сегментов)
- [ ] В stdout печатается краткий отчёт на русском: число окон, число окон в откате, число абзацев и предложений, число слов, путь к файлу
- [ ] При переданном --log-dir промпты и ответы claude складываются туда через tools/claude_cli.py

## Контекст

Решения владельца, на которых держится задача: «claude расставляет пунктуацию, заглавные и абзацы, слова менять запрещено (таймкоды сохраняются)»; «окна по ~100 сегментов (чанков), склейка по порядку»; «сверять; при расхождении в окне — взять для этого окна дословный текст без пунктуации и пометить место в файле, код возврата ненулевой»; «каждое предложение — отдельная строка с префиксом [ЧЧ:ММ:СС]» (сама строка рендерится другой задачей, здесь нужны предложения и их таймкоды).

Выбранная модель — GigaAM v3_rnnt: она выдаёт сплошной поток строчными без точек, числа словами. Именно поэтому пунктуация восстанавливается отдельным шагом, и именно поэтому запрет на цифры в промпте важен: «2» вместо «два» — это изменение слова, то есть откат окна.

Вход — schema `transcript/1` из tools/transcribe.py: поля `schema`, `source`, `source_duration`, `model`, `text`, `metrics`, `segments`; каждый сегмент — `{index, start, end, text, words: [{text, start, end}]}`, таймкоды абсолютные по записи, слов у сегмента может не быть (пустой чанк). Разбор транскрипта можно подсмотреть в tools/outputs.py (parse_transcript) и tools/align_timecodes.py (read_transcript) — повторять их код не обязательно.

Схема `punctuated/1` зафиксирована в критериях приёмки и является контрактом с задачами «tools/summarize.py» и «tools/render_doc.py», которые пишутся параллельно и читают этот файл. Отступать от набора полей нельзя, добавлять свои поля можно.

Вызов claude делается только через `tools/claude_cli.py` (готов к началу этой задачи): `available()`, `ask(prompt, timeout=, attempts=, log_dir=, tag=)`, исключения `ClaudeUnavailable` и `ClaudeFailed`. Свой subprocess к claude не писать.

Разбиение на предложения: границы — `.`, `!`, `?`, `…` (и их комбинации) с последующим пробелом и заглавной буквой или концом абзаца; предложение без букв и цифр не создаётся; абзац — блок, отделённый пустой строкой в ответе claude. В откатившемся окне предложениями считаются сегменты: одна строка на сегмент.

Прогоны пишут только внутрь data/, который закрыт корневым .gitignore: текст лекции в репозиторий попадать не должен, фикстуры selftest — только во временных каталогах.

## Не входит в задачу

Не делать саммари, не собирать итоговый .md, не рендерить строки `[ЧЧ:ММ:СС]` (это задачи 3 и 4), не менять tools/transcribe.py, tools/outputs.py, tools/check_timecodes.py, схемы transcript/1 и chunk-plan/1, не трогать scripts/*, не делать повторные вызовы claude ради улучшения качества пунктуации, не чинить ошибки распознавания.
