# README проекта и .gitignore

**Правит:** README.md .gitignore 

## Цель

Должен появиться `README.md` на русском — короткое и честное описание проекта: что это за транскрибатор, какой вход и выход, какие ограничения по железу и бюджету, какой сейчас статус (стадия ресерча, кода пайплайна нет), как устроен репозиторий и где лежат документы ресерча и план. Плюс `.gitignore`, который не пускает в репозиторий медиафайлы, секреты и мусор окружения.

## Критерии приёмки

- [ ] `README.md` на русском и содержит: описание проекта (транскрибация записей лекций на русском), вход (webm/mp4 запись лекции), выход целевого MVP (связный текст + SRT/VTT с таймкодами), минимально достаточный выход (только текст)
- [ ] Есть раздел «Ограничения»: бюджет 0 (только бесплатные тарифы и локальные модели), железо Mac M5 с 16 ГБ памяти, распознавание по умолчанию локальное
- [ ] Есть раздел «Статус»: сейчас стадия анализа и ресерча, продуктового кода нет
- [ ] Есть раздел «Структура репозитория» со ссылками ровно на пути: docs/analysis/example-recordings.md, docs/research/asr-models.md, docs/research/benchmark-plan.md, docs/research/summarization-apis.md, docs/plan.md, docs/decisions/delivery-form.md, scripts/inspect_media.sh, scripts/make_sample.sh
- [ ] Есть раздел «Форма поставки»: зафиксировано, что выбор между веб-сервисом с загрузкой файла и Telegram-ботом отложен владельцем, а ядро делается как переносимый пайплайн, не зависящий от интерфейса
- [ ] Есть раздел «Требования к окружению»: macOS, ffmpeg/ffprobe (установка через brew), Python 3.x, платные ключи не нужны
- [ ] Есть раздел «Данные»: где лежат примеры записей и что сами медиафайлы в git не хранятся
- [ ] `.gitignore` закрывает: `.venv/`, `__pycache__/`, `*.pyc`, `.DS_Store`, `.env`, `data/`, `out/`, медиа (`*.webm`, `*.mp4`, `*.mkv`, `*.wav`, `*.mp3`, `*.m4a`)
- [ ] README не содержит выводов ресерча и сравнений моделей — только описание проекта и ссылки на документы
- [ ] Ссылок на файлы вне перечисленного списка в README нет

## Контекст

Решения владельца, которые надо зафиксировать в README: бюджет 0 — только бесплатные тарифы и локальные модели; железо MacBook Apple Silicon M5, 16 ГБ унифицированной памяти, macOS; распознавание речи по умолчанию локальное (записи не уходят наружу), облако допустимо для саммари; язык документации — русский; целевой MVP — связный текст транскрипта + SRT/VTT с таймкодами, минимально достаточный вариант — только текст; диаризация, извлечение слайдов и OCR — вне MVP; саммари — этап после MVP. Форма поставки окончательно не выбрана: владелец колеблется между веб-сервисом с загрузкой файла и Telegram-ботом, поэтому ядро делается как переносимый пайплайн, не зависящий от интерфейса — это надо прямо написать, а не умалчивать.

Единственный пример записи: `vidio_example/Лекция 1 01.09.26 (1).webm`. Медиафайлы в git не хранятся.

Полная карта документов проекта — их создают другие задачи параллельно, файлов на момент твоей работы может ещё не быть, но пути фиксированы и ссылаться надо именно на них: docs/analysis/example-recordings.md (разбор примера записи), docs/research/asr-models.md (обзор моделей распознавания), docs/research/benchmark-plan.md (протокол замера качества), docs/research/summarization-apis.md (бесплатные LLM API для саммари), docs/plan.md (план работ), docs/decisions/delivery-form.md (веб-сервис или Telegram-бот), scripts/inspect_media.sh, scripts/make_sample.sh. Эти файлы не создавай и не правь — только ссылайся.

## Не входит в задачу

Не писать выводы ресерча и сравнения моделей (их место — в docs/), не писать план работ, не создавать и не править файлы в docs/ и scripts/, не писать код пайплайна, не инициализировать окружение и не ставить зависимости.
