# scripts/transcribe_gigaam.sh — проброс --drop-pause и режим без выбрасывания пауз

**Правит:** scripts/transcribe_gigaam.sh 

## Цель

Сквозной скрипт прогона умеет управлять выбрасыванием пауз: новый флаг `--drop-pause <сек>` передаётся в `tools/chunker.py`, а флаг `--keep-pauses` означает «паузы не выбрасывать вовсе». Выбранный режим виден в выводе скрипта и в `summary.md`, чтобы два прогона одной записи нельзя было спутать. Поведение по умолчанию не меняется: без новых флагов нарезка идёт ровно как сейчас.

## Критерии приёмки

- [ ] `bash scripts/transcribe_gigaam.sh --help` описывает `--drop-pause <сек>` и `--keep-pauses` и возвращает 0
- [ ] `--drop-pause <сек>` передаётся в вызов `tools/chunker.py`; без флага вызов остаётся прежним, без лишних аргументов
- [ ] `--keep-pauses` приводит к тому, что паузы не выбрасываются: в `plan.json` `dropped_seconds` равен 0, покрытие равно длительности входа
- [ ] Значение, переданное одновременно с `--keep-pauses`, не приводит к противоречию: правило разрешения конфликта описано в справке и реализовано
- [ ] Нечисловое или отрицательное значение `--drop-pause` — понятная ошибка до начала прогона, а не падение внутри нарезчика
- [ ] Режим нарезки печатается в блоке «Сводка плана» и попадает в строку «Нарезка» в `summary.md`
- [ ] `bash -n scripts/transcribe_gigaam.sh` проходит; существующие флаги (`--input`, `--outdir`, `--models`, `--device`, `--download-root`, `--skip-prepare`, `--keep-chunks`, `--no-chunks`) работают как раньше

## Контекст

Решение владельца: замер по новому эталону делается в двух режимах нарезки — с выбрасыванием пауз (как сейчас по умолчанию, `--drop-pause 2.0`) и без выбрасывания, на обеих моделях. Сейчас `scripts/transcribe_gigaam.sh` вызывает `tools/chunker.py` без параметров нарезки, то есть контрольный прогон без выбрасывания одной командой не воспроизвести.

У `tools/chunker.py` уже есть флаг `--drop-pause <сек>` (по умолчанию 2.0, значение должно быть неотрицательным), отключения как такового у него нет — «не выбрасывать» выражается очень большим значением, заведомо превышающим длину любой паузы в записи. Выбор конкретного способа реализации `--keep-pauses` за исполнителем, главное — чтобы `dropped_seconds` в плане получился 0 и это было видно в выводе.

Скрипт — единственная команда прогона, его вывод целиком кладут в лог и потом разбирают, поэтому режим нарезки обязан читаться из лога без сверки с историей команд.
