# tools/summarize.py — саммари лекции одним вызовом claude

**Зависит от:** 180

**Правит:** tools/summarize.py 

## Цель

Должен появиться инструмент tools/summarize.py, который берёт punctuated.json (схема punctuated/1), одним вызовом claude делает саммари всей записи и пишет markdown-фрагмент с тремя разделами: изложение, темы с таймкодами, решения/задачи/договорённости. Если claude недоступен, не авторизован или вызов провалился, фрагмент всё равно создаётся — с пометкой «не получено» и причиной, а код возврата ненулевой.

## Критерии приёмки

- [ ] `python tools/summarize.py --selftest` проходит без установленного claude: проверки на подставном claude покрывают успешный ответ с тремя разделами, ответ без разделов, пустой ответ, отсутствие бинарника, недопустимый вход
- [ ] Флаги: `--punctuated <путь>` или `--transcript <путь>` (хотя бы один обязателен; при обоих приоритет у --punctuated), `--out <путь>`, `--timeout <сек>`, `--attempts <число>`, `--log-dir <каталог>`, `--selftest`, `-h/--help` со справкой на русском
- [ ] Саммари делается ровно одним вызовом claude по всему тексту; в промпт текст подаётся строками `[ЧЧ:ММ:СС] предложение`, и промпт явно требует брать таймкоды только из этих строк, не выдумывая своих
- [ ] Фрагмент на выходе — markdown с тремя разделами уровня `###` в фиксированном порядке и с фиксированными заголовками: `### Изложение` (связный текст, 3–8 абзацев), `### Темы` (список строк вида `- [ЧЧ:ММ:СС] название темы`), `### Решения, задачи, договорённости` (список строк вида `- [ЧЧ:ММ:СС] формулировка`; если ничего такого в записи нет — одна строка «не прозвучало»)
- [ ] Заголовков уровня `#` и `##` в фрагменте нет: он вставляется в итоговый документ под готовый заголовок `## Саммари`
- [ ] Если ответ claude получен, но три заголовка в нём не найдены, ответ сохраняется как есть под `### Изложение`, в stderr печатается предупреждение, код возврата 0
- [ ] Если саммари не получено (нет claude, не авторизован, таймаут, ненулевой код, пустой ответ), файл --out содержит `### Изложение` с текстом «Саммари не получено: <причина>.» и пустые разделы «Темы» и «Решения, задачи, договорённости» с той же пометкой; код возврата 1, причина также печатается в stderr
- [ ] Код возврата 2 — вход непригоден (файла нет, не та схема, нет предложений); при этом файл --out не создаётся и не перетирается
- [ ] Таймкоды в промпте и в проверках формата — `ЧЧ:ММ:СС` с часами без ограничения на два знака у записей длиннее суток не требуется, но запись 02:35:29 отображается как `02:35:29`
- [ ] Текст лекции и ответы claude пишутся только в указанные флагами пути; при --log-dir промпт и ответ сохраняются через tools/claude_cli.py
- [ ] Только стандартная библиотека, стиль и структура как у остальных tools/*.py

## Контекст

Решения владельца: «изложение + темы с таймкодами + решения/задачи/договорённости» в саммари; «саммари отдельным вызовом по всему тексту»; «сохранить расшифровку, вместо саммари пометка „не получено“, код возврата ненулевой»; вызов — `claude -p <промпт>` с моделью по умолчанию.

Вход — файл схемы `punctuated/1`, который параллельно делает задача «tools/punctuate.py». Контракт зафиксирован, на него и пиши: `{schema: "punctuated/1", source, source_duration, transcript, model, windows: [{index, segments: [первый, последний], status: "ok"|"fallback", reason}], paragraphs: [{index, window, sentences: [первый, последний]}], sentences: [{index, start, end, text, window, fallback}], text, stats: {windows, fallback_windows, paragraphs, sentences, words}}`. Таймкоды в секундах от начала записи, числа с округлением до 3 знаков. Фикстуры для selftest собирай сам по этой схеме, не ожидая готового punctuate.py.

Режим `--transcript` нужен как подстраховка: на вход тогда идёт `transcript/1` из tools/transcribe.py (`segments: [{index, start, end, text, words}]`), строки для промпта собираются по сегментам. Текст там дословный, без пунктуации — саммари по нему хуже, но делается.

Вызов claude — только через `tools/claude_cli.py` (готов к началу задачи): `available()`, `ask(prompt, timeout=, attempts=, log_dir=, tag=)`, `ClaudeUnavailable`, `ClaudeFailed`. Свой subprocess не писать. Полная лекция — около 2,5 часов и порядка 25 тысяч слов, то есть промпт на сотни тысяч символов: учитывай, что claude_cli.ask поднимает ClaudeFailed, если промпт длиннее безопасного предела аргумента, и обработай это как «саммари не получено» с внятной причиной.

Речь русская, записи — лекции и рабочие созвоны, в тексте встречаются имена коллег и названия продуктов: промпт должен требовать русский язык ответа и запрещать выдумывать факты, которых нет в тексте.

## Не входит в задачу

Не восстанавливать пунктуацию и не резать текст на окна (это задача 2), не собирать итоговый .md и не писать заголовок `## Саммари` (задача 4), не делать несколько вызовов claude и map-reduce по частям, не трогать существующие tools/*.py и scripts/*, не фиксировать модель claude.
