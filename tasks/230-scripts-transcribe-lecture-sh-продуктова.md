# scripts/transcribe_lecture.sh — продуктовая команда: медиафайл на вход, один markdown на выход

**Зависит от:** 190 200 210 220

**Правит:** scripts/transcribe_lecture.sh 

## Цель

Должна появиться отдельная точка входа scripts/transcribe_lecture.sh: человек указывает медиафайл, скрипт целиком готовит из него 16 кГц моно WAV, строит план нарезки без выбрасывания пауз, распознаёт GigaAM v3_rnnt, рендерит .txt и .srt, проверяет таймкоды, восстанавливает пунктуацию через claude, делает саммари и собирает один итоговый файл data/output/<имя файла>-<дата>.md с саммари и расшифровкой по предложениям с таймкодами. Все промежуточные файлы остаются в рабочем подкаталоге рядом с итогом. Скрипт прогнан целиком и работает.

## Контекст

Формулировка владельца: «следующий этап — сделать нормальную выгрузку и сбор всех артефактов транскрибации в один общий файл… я вызываю команду для транскрибации, указываю, какой именно файл нужно разобрать, он обрабатывается и возвращается готовый, с саммари, и после с точной транскрибацией с таймкодами».

Зафиксированные решения владельца, которые эта задача обязана соблюсти: модель — GigaAM v3_rnnt в режиме без выбрасывания пауз (--keep-pauses) — выбор сделан по замеру, см. раздел 8 docs/research/benchmark-plan.md; на вход — любой медиафайл, конвертация внутри, обрабатывается запись целиком; итог — Markdown `data/output/<имя файла>-<дата>.md`; в итоге только саммари и расшифровка, технического блока не нужно; промежуточные файлы (WAV, plan.json, chunks, transcript.json) плюс .srt и .txt остаются в рабочем подкаталоге рядом с итогом; флаг повторного прохода по готовому transcript.json нужен; если claude недоступен или упал — расшифровку сохранить, вместо саммари пометка «не получено», код возврата ненулевой; при расхождении слов в окне пунктуации — дословный текст для этого окна, пометка в файле и ненулевой код.

Бенчмарк scripts/transcribe_gigaam.sh остаётся как есть: это сравнение двух чекпойнтов со своим входом и выходом в data/transcripts/. Общие функции к этому моменту уже лежат в scripts/lib/common.sh: `die`, `warn`, `fmt_bytes`, `resolve_python`, `require_tools`, `require_python_gigaam`, `require_weights <модель> <download-root>`, `pkg_version`, `print_env_block`, `print_input_block`, `plan_summary <plan.json> <режим>`, `to_wav <вход> <выход>`. Пользуйся ими, библиотеку при этом не правь — её файл принадлежит другой задаче; если чего-то не хватает, определи функцию локально в своём скрипте.

Готовые CLI, которые надо связать (фактические флаги читай в коде, контракты зафиксированы):
- `python tools/chunker.py --input <wav> --outdir <dir> --drop-pause 86400` — пишет <dir>/plan.json и <dir>/chunks/chunk_000.wav…
- `python tools/transcribe.py --plan <plan.json> --model v3_rnnt --out <transcript.json> --device cpu --download-root ~/.cache/gigaam`
- `python tools/outputs.py --transcript <transcript.json> --txt <файл> --srt <файл>`
- `python tools/check_timecodes.py --transcript <transcript.json> --srt <файл> --json <файл>` — 0 все проверки прошли, 1 есть FAIL, 2 вход непригоден
- `python tools/punctuate.py --transcript <transcript.json> --out <punctuated.json> --window 100 --log-dir <dir>/claude` — 0 все окна прошли сверку слов, 1 есть окна с дословным текстом или claude недоступен, 2 вход непригоден
- `python tools/summarize.py --punctuated <punctuated.json> --out <dir>/summary.md --log-dir <dir>/claude` — 0 саммари получено, 1 не получено (файл с пометкой всё равно создан), 2 вход непригоден
- `python tools/render_doc.py --punctuated <punctuated.json> --summary <dir>/summary.md --out <итог.md>` — 0 документ без пометок, 1 документ с пометками, 2 вход непригоден

Прогон на 5-минутном фрагменте идёт на CPU около минуты плюс вызовы claude: запускай Bash с большим таймаутом или в фоне. Веса v3_rnnt уже лежат в ~/.cache/gigaam, качать ничего не нужно и нельзя. Проверка раннера запускает только `bash -n` и `--help`, поэтому живые прогоны делай сам и приводи их вывод в результате задачи.

Если сквозной прогон вскрыл ошибку в tools/punctuate.py, tools/summarize.py, tools/render_doc.py или tools/claude_cli.py — чини на месте, параллельных авторов у этих файлов к этому моменту нет; схемы transcript/1, chunk-plan/1, checks/1 и punctuated/1 при этом не менять, после правки прогнать --selftest изменённого инструмента.

Не менять scripts/transcribe_gigaam.sh, scripts/lib/common.sh, scripts/make_sample.sh, scripts/inspect_media.sh, не менять tools/chunker.py, tools/transcribe.py, tools/outputs.py, tools/check_timecodes.py, tools/score.py, tools/align_timecodes.py и их схемы, не добавлять в продуктовый прогон вторую модель и сравнительную таблицу, не считать WER/CER и не добавлять технический блок в итоговый документ, не прогонять полную запись 02:35 (это решение владельца, а не часть задачи), не править README.md и .gitignore, не ставить пакеты, не качать веса, не вызывать chmod.

**В:** Что именно значит «точная транскрибация» в итоговом файле: дословный выход модели как есть (сплошные строчные, без точек) или текст, которому claude расставил пунктуацию и заглавные без изменения слов?  
**О:** claude расставляет пунктуацию, заглавные и абзацы, слова менять запрещено (таймкоды сохраняются)

**В:** С какой гранулярностью ставить таймкоды в итоговом файле?  
**О:** Таймкод на каждое предложение

**В:** Какой формат и куда кладётся итоговый файл?  
**О:** Markdown: data/output/<имя файла>-<дата>.md

**В:** Что должно быть в саммари и какого размера?  
**О:** Изложение + темы с таймкодами + решения/задачи/договорённости

**В:** Что делать, если claude CLI недоступен, не авторизован или упал на саммари?  
**О:** Сохранить расшифровку, вместо саммари пометка «не получено», код возврата ненулевой

**В:** Что принимает команда на входе: любой медиафайл (webm/mp4/mp3) с подготовкой 16 кГц моно WAV внутри, или по-прежнему только готовый WAV?  
**О:** Любой медиафайл, конвертация внутри, обрабатывается запись целиком

**В:** Новая команда — отдельная точка входа, а существующий scripts/transcribe_gigaam.sh остаётся как есть (бенчмарк двух моделей)?

**В:** Как вызывать claude CLI и какой моделью? Это неинтерактивный вызов из скрипта, модель влияет и на цену, и на качество пунктуации.  
**О:** claude -p <промпт> с моделью по умолчанию (её не фиксируем)

**В:** Транскрипт полной лекции (02:35) — это десятки тысяч слов, в один промпт пунктуация целиком не влезет. Резать текст на окна и склеивать результат?  
**О:** Окна по ~100 сегментов (чанков), склейка по порядку; саммари отдельным вызовом по всему тексту

**О:** Сверять; при расхождении в окне — взять для этого окна дословный текст без пунктуации и пометить место в файле, код возврата ненулевой

**В:** В каком виде таймкод у предложения и от какого нуля он считается?  
**О:** Каждое предложение — отдельная строка с префиксом [ЧЧ:ММ:СС]

**О:** Промежуточные файлы (WAV, plan.json, chunks, transcript.json) в рабочем подкаталоге рядом с итогом, плюс .srt и .txt; флаг повторного прохода по готовому transcript.json есть
