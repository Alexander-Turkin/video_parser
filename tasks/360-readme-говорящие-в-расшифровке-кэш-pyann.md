## Цель

README должен описывать проект с распознаванием говорящих по фактическому коду: что в расшифровке каждая строка идёт как `[00:12:34] Преподаватель: фраза`, что роли ставит claude по смыслу поверх «Говорящих» от pyannote, что веса и кэш pyannote готовятся руками и без них шаг падает с кодом 2, что диаризация идёт всегда и отключается `--no-diarize`, чего стоит её время на CPU, какие файлы появляются в рабочем подкаталоге и какие из них остаются после чистки.
