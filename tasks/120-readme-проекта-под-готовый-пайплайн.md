## Цель

Должен появиться README.md на русском — короткое и честное описание проекта по фактическому коду: что делает транскрибатор, что нужно поставить, как одной командой получить расшифровку, какие инструменты есть в репозитории, куда пишутся результаты и какие у пайплайна ограничения.

## Критерии приёмки

- [ ] Описание проекта: локальная транскрибация записей лекций на русском через GigaAM; вход — запись лекции webm/mp4; выход — .txt (абзацы), .srt (субтитры по пословным таймкодам) и .json (схема transcript/1 с сегментами, словами и метриками)
- [ ] Раздел «Требования»: macOS на Apple Silicon, `brew install ffmpeg`, Python 3.12 в .venv проекта с gigaam 0.2.0 и torch; веса в ~/.cache/gigaam скачиваются вручную заранее — перечислены нужные файлы (v3_rnnt.ckpt; v3_e2e_rnnt.ckpt и v3_e2e_rnnt_tokenizer.model) и сказано, что инструменты сами ничего не качают и падают с понятной ошибкой без весов; платные ключи и сеть не нужны
- [ ] Раздел «Быстрый старт» с командой из справки scripts/transcribe_gigaam.sh (с `mkdir -p data/transcripts` и сохранением лога через tee) и пояснением, что прогон идёт на CPU и сколько он занимает на 5-минутном фрагменте — цифра взята из docs/analysis/gigaam-local-run.md, а не придумана
- [ ] Раздел «Что внутри»: по одной-две строки на scripts/inspect_media.sh, scripts/make_sample.sh, scripts/transcribe_gigaam.sh, tools/chunker.py, tools/transcribe.py, tools/outputs.py, tools/check_timecodes.py — назначение и главная команда; флаги взяты из фактического --help, у каждого инструмента упомянут --selftest
- [ ] Раздел «Результаты»: раскладка data/transcripts/ (plan.json, chunks/, <модель>/transcript.json|.txt|.srt, checks.*, summary.md); явно сказано, что data/ и записи из vidio_example/ закрыты .gitignore и в git не попадают
- [ ] Раздел «Ограничения»: чанк ≤ 24 с (лимит transcribe() в 25 с), паузы длиннее 2 с выбрасываются — в SRT на них дыры; v3_rnnt выдаёт текст без пунктуации и заглавных, v3_e2e_rnnt — с ними; пока прогон проверен только на 5-минутном фрагменте; интерфейс (веб-сервис или Telegram-бот) не выбран — ядро сделано CLI-пайплайном, не зависящим от интерфейса
- [ ] Раздел «Документы» со ссылками ровно на: docs/analysis/example-recordings.md, docs/analysis/gigaam-local-run.md, docs/research/asr-models.md, docs/research/benchmark-plan.md — каждая с одной строкой, что там
- [ ] Все пути и ссылки в README существуют в репозитории; нет ссылок на docs/research/summarization-apis.md, docs/plan.md, docs/decisions/** и прочие несуществующие файлы
- [ ] README не пересказывает выводы ресерча и сравнение моделей — только описание проекта и ссылки; строк расшифровки лекции в нём нет

## Контекст

Ресерч закончен, проект перешёл к реализации: к моменту этой задачи готовы tools/chunker.py, tools/transcribe.py, tools/outputs.py, tools/check_timecodes.py и scripts/transcribe_gigaam.sh, а docs/analysis/gigaam-local-run.md содержит цифры реального прогона. Читай код и --help каждого инструмента и описывай фактические флаги и пути; если что-то разошлось с этим описанием — доверяй коду.

Решения владельца: бюджет 0, распознавание локальное, железо MacBook Apple Silicon M5, 16 ГБ; язык документации — русский; целевой результат — связный текст + SRT с таймкодами; диаризация, OCR слайдов и саммари — вне текущего объёма, упоминать их не нужно. Форма поставки (веб-сервис или Telegram-бот) владельцем не выбрана — об этом одна строка в «Ограничениях», без сравнения вариантов.

Корневой .gitignore уже есть и закрывает .venv/, data/, vidio_example/, медиафайлы и .claude-runner/ — не трогай его, только опиши в README.

Права: раннеру разрешены python из .venv, ffmpeg/ffprobe и `bash scripts/*`, запрещён chmod. --help инструментов можно и нужно запускать, чтобы списать флаги; тяжёлый прогон для README не нужен.

## Не входит в задачу

Не править код в scripts/** и tools/**, не трогать docs/** и корневой .gitignore, не запускать полный прогон, не писать выводы ресерча и сравнения моделей, не описывать саммари, диаризацию и OCR, не создавать других файлов кроме README.md.
