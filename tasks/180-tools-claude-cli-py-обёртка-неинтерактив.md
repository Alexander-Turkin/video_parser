# tools/claude_cli.py — обёртка неинтерактивного вызова claude -p

**Правит:** tools/claude_cli.py 

## Цель

Должен появиться один модуль tools/claude_cli.py, через который остальные инструменты вызывают Claude CLI: находит бинарник claude, проверяет его доступность, делает неинтерактивный вызов `claude -p <промпт>` с таймаутом и повторами, возвращает текст ответа, а любую неудачу (нет бинарника, не авторизован, таймаут, ненулевой код, пустой ответ) превращает в типизированное исключение с понятным русским сообщением. Дополнительно умеет складывать каждый промпт и каждый ответ в файлы для разбора. Модуль одновременно и библиотека (его импортируют tools/punctuate.py и tools/summarize.py), и самостоятельный CLI со --selftest и режимом проверки доступности.

## Критерии приёмки

- [ ] `python tools/claude_cli.py --selftest` проходит без установленного claude: все проверки идут на подставных скриптах-заглушках в временном каталоге (успех, ненулевой код, пустой stdout, таймаут, отсутствие бинарника)
- [ ] `python tools/claude_cli.py --probe` печатает по-русски, доступен ли claude и какой бинарник найден; код возврата 0 — доступен, 1 — нет
- [ ] `python tools/claude_cli.py --ask <файл-с-промптом>` печатает ответ в stdout (ручная проверка живым claude), `--help` — справка на русском
- [ ] Публичный API зафиксирован и описан в docstring модуля: `available() -> tuple[bool, str]`, `ask(prompt: str, *, timeout: float = 300, attempts: int = 2, log_dir: str | None = None, tag: str = "call") -> str`, исключения `ClaudeUnavailable` (нет бинарника / не авторизован) и `ClaudeFailed` (упал, таймаут, пустой ответ), обе с человекочитаемым `str(e)` на русском
- [ ] Команда формируется ровно как `claude -p <промпт>`: промпт одним аргументом, модель не задаётся (используется модель по умолчанию), интерактивные и потоковые флаги не передаются; путь к бинарнику берётся из переменной окружения CLAUDE_BIN, иначе из PATH
- [ ] Вызов идёт без наследования stdin (stdin закрыт или /dev/null), с таймаутом (по умолчанию 300 с) и повторами (по умолчанию 2 попытки с паузой между ними); повтор делается только на таймауте и ненулевом коде, но не при отсутствии бинарника
- [ ] Промпт длиннее безопасного предела аргумента (ARG_MAX с запасом, предел задан именованной константой) не отправляется: поднимается ClaudeFailed с сообщением, сколько символов пришло и какой предел
- [ ] При переданном log_dir каждый вызов сохраняет два файла `<tag>-<номер>.prompt.txt` и `<tag>-<номер>.response.txt`; каталог создаётся при необходимости, существующие файлы не перетираются
- [ ] Только стандартная библиотека, никаких сетевых клиентов и ключей API; оформление и стиль как у остальных tools/*.py (шапка с объяснением зачем, русские сообщения, die/warn, --selftest)

## Контекст

Решение владельца: вызывать именно `claude -p <промпт>` с моделью по умолчанию, модель не фиксируем. Этим модулем будут пользоваться два инструмента: восстановление пунктуации (много вызовов по окнам текста) и саммари (один большой вызов), поэтому таймаут, число попыток и каталог логов — параметры, а не константы.

Поведение при недоступности claude диктуется требованием владельца к пайплайну: расшифровка обязана сохраниться, вместо саммари ставится пометка «не получено», код возврата прогона ненулевой. Значит модуль не должен сам ничего печатать в stdout и не должен завершать процесс — он только поднимает исключение, а решение принимает вызывающий инструмент.

В проекте нет pyproject и пакета: tools/*.py — самостоятельные файлы, которые запускаются как `python tools/<имя>.py` и импортируются друг из друга по пути. У каждого инструмента есть встроенный `--selftest`, проходящий без тяжёлых зависимостей — это и способ проверки задачи. Смотри tools/score.py и tools/align_timecodes.py как образец структуры (ToolError/UsageError, die, parse_args, selftest).

## Не входит в задачу

Не писать сами промпты пунктуации и саммари (это задачи 2 и 3), не разбирать transcript.json, не трогать существующие tools/*.py и scripts/*, не добавлять зависимости, не обращаться к API Anthropic напрямую, не фиксировать модель.
