# tools/cleanup_runs.py — диаризация, фразы и роли остаются после чистки

**Правит:** tools/cleanup_runs.py 

## Цель

Чистка рабочего подкаталога не должна выбрасывать результаты, которые стоят десятки минут CPU: список файлов-хранителей расширяется с трёх до шести — `transcript.json`, `punctuated.json`, `summary.md`, `diarization.json`, `speakers.json`, `roles.json`. Всё остальное удаляется как раньше, остальное поведение инструмента не меняется.

## Критерии приёмки

- [ ] Список хранителей в одном месте кода (как сейчас) содержит ровно шесть имён: `transcript.json`, `punctuated.json`, `summary.md`, `diarization.json`, `speakers.json`, `roles.json`
- [ ] `--help` и отчёт в stdout перечисляют шесть хранителей; правило «каталог без единого хранителя удаляется целиком» действует по новому списку
- [ ] Хранителем по-прежнему считается только обычный файл с таким именем: символическая ссылка или каталог с именем `diarization.json` удаляется, цель ссылки не затрагивается
- [ ] Остальное поведение не меняется: область работы (`data/output` без аргументов, `--run <каталог>` — один каталог), `--dry-run`, рекурсивный обход без перехода по ссылкам, формат отчёта, коды возврата 0/1/2
- [ ] `python tools/cleanup_runs.py --selftest` проходит, и в селф-тест добавлены проверки на три новых хранителя (остаются при чистке) и на каталог, в котором из шести файлов есть только `diarization.json` (каталог не удаляется)

## Контекст

Диаризация pyannote на CPU считает примерно в реальном времени: на лекции 02:35:29 это десятки минут, и потерять `diarization.json` при чистке означает оплатить их второй раз. `speakers.json` и `roles.json` дешевле, но без них не перерисовать документ с ярлыками, а `roles.json` ещё и стоит вызова claude. Поэтому три новых файла прогона попадают в список хранителей — это решение планировщика, владельцу этот вопрос задавался и остался без внятного ответа.

Устройство файла сейчас: список хранителей задан одной константой, обход каталога идёт своим рекурсивным проходом через `os.scandir(follow_symlinks=False)`, отчёт печатается по верхнеуровневым записям, удаление необратимо (ни корзины, ни архива) — поэтому задача ограничена расширением списка и правкой текстов и селф-теста, без переделки логики обхода.

## Не входит в задачу

Не менять логику обхода и удаления, не добавлять флагов (в том числе выбора корня или своего списка хранителей), не трогать `scripts/transcribe_lecture.sh` (его `--clean` зовёт этот инструмент как есть), другие `tools/*.py` и README.
