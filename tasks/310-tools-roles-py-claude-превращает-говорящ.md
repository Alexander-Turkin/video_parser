# tools/roles.py — claude превращает «Говорящий N» в роли «Преподаватель» и «Студент N»

**Правит:** tools/roles.py 

## Цель

Нужен самостоятельный CLI `tools/roles.py`: по файлу `speakers/1` он одним вызовом claude определяет, кто из говорящих кто по смыслу разговора, и пишет JSON схемы `roles/1` — соответствие «Говорящий N → роль», где роли называются «Преподаватель» и «Студент 1», «Студент 2», … Если claude недоступен или ответил негодно, файл всё равно пишется: роли в нём остаются именами говорящих, помечен статус отката с причиной и код возврата 1 — расшифровка не должна терять ярлыки совсем из-за одного неудачного вызова.

## Критерии приёмки

- [ ] `python tools/roles.py --selftest` проходит на подставном claude (как это сделано в `tools/punctuate.py`) и не делает живых вызовов; `--help` печатает русскую справку, код 0
- [ ] Флаги: `--speakers <speakers.json>`, `--out <roles.json>`, `--timeout`, `--attempts`, `--log-dir`, `--selftest`, `--help`; вызов claude идёт только через `tools/claude_cli.py`, ровно один на прогон
- [ ] В промпте по каждому говорящему: имя, доля речи, число фраз и до 15 показательных фраз с таймкодами; требование вернуть строки строго вида `Говорящий N -> Роль`, без пояснений; ведущий занятие — «Преподаватель» (он один), остальные — «Студент 1», «Студент 2», … с нумерацией по убыванию доли речи
- [ ] Разбор ответа устойчив: лишние строки и пояснения игнорируются, неизвестные имена говорящих — предупреждение в stderr, роль приводится к одной строке без переносов и длиной не больше 40 символов; говорящий, которого claude не назвал, получает «Студент N»; если «Преподавателем» назвали нескольких, им остаётся тот, у кого больше доля речи, остальные становятся «Студент N»
- [ ] Говорящий всего один — роль «Преподаватель» присваивается без вызова claude, в отчёте сказано почему, код 0
- [ ] В `speakers/1` нет ни одного говорящего — файл `roles/1` пишется с пустым соответствием и статусом `skip`, код 0
- [ ] Записанный файл — схема `roles/1` с полями ровно: `schema`, `speakers` (путь к входу), `status` (`ok` | `fallback` | `skip`), `reason`, `roles` — `[{"speaker", "role", "share", "source": "claude" | "default" | "fallback"}]`, `stats` — `{"speakers", "from_claude", "defaulted"}`
- [ ] Коды возврата: `0` — роли получены; `1` — claude не ответил или ответ негоден, в файле роли равны именам говорящих и стоит `status: "fallback"` с причиной (причина дублируется в stderr); `2` — вход непригоден. При коде 2 `--out` не создаётся и существующий файл не перетирается
- [ ] Только стандартная библиотека плюс импорт `claude_cli`, свой разбор аргументов, русские сообщения, `ensure_ascii=False`, отступ 2

## Контекст

Ответы владельца (из `.claude-runner/plan-answers.jsonl`): «Гибрид: pyannote по голосу даёт „Говорящий 1/2/3“, claude по тексту превращает их в роли»; «Роли по смыслу: „Преподаватель“, „Студент 1“, „Студент 2“»; «Нужен ли в документе состав говорящих... — Нет, достаточно ярлыков в строках расшифровки».

Схема входа `speakers/1` (её пишет задача про `tools/speakers.py`, формат зафиксирован планом): `{"schema": "speakers/1", "transcript", "punctuated", "diarization", "pause", "speakers": [{"name": "Говорящий 1", "label", "phrases", "speech_seconds", "share"}], "phrases": [{"index", "start", "end", "text", "speaker", "sentences", "paragraph", "fallback", "reason"}], "stats": {...}}`.

Что уже есть: `tools/claude_cli.py` — единственное место запуска claude (`available()`, `ask()`, исключения `ClaudeUnavailable` и `ClaudeFailed` с русским текстом, логи промптов и ответов по `--log-dir`/`--tag`). Образец устройства «один вызов claude + разбор ответа + пометка при неудаче» — `tools/summarize.py`; образец селф-теста на подставном claude — `tools/punctuate.py`. Поведение «без claude прогон не падает, но код ненулевой и в документе пометка» — принятое правило проекта, см. README, раздел «Требования».

Этот файл читают `tools/render_doc.py` и `tools/summarize.py` (ярлык строки = роль из `roles/1`, если её нет — имя говорящего), поэтому состав полей менять нельзя.

## Не входит в задачу

Не строить фразы и не делать атрибуцию говорящих — это вход из `speakers/1`. Не рендерить markdown, не трогать `tools/render_doc.py`, `tools/summarize.py`, `tools/claude_cli.py`, `tools/speakers.py`, `scripts/` и README. Не вводить других названий ролей помимо «Преподаватель» и «Студент N» в промпте. Не делать второй вызов claude и не просить его переписывать текст расшифровки.
