# Ресерч бесплатных LLM API для саммари и тезисов по транскрипту

**Правит:** docs/research/summarization-apis.md 

## Цель

Должен появиться `docs/research/summarization-apis.md` — обзор способов получить саммари, тезисы и ключевые термины по транскрипту часовой-двухчасовой лекции на русском, строго в рамках бесплатного доступа: облачные free tier и локальные модели на 16 ГБ. С арифметикой по токенам, стратегией обработки длинного транскрипта, готовыми промптами на русском и однозначной рекомендацией основного варианта и fallback.

## Критерии приёмки

- [ ] Таблица по >=6 вариантам с бесплатным доступом с колонками: провайдер и доступные модели, лимиты бесплатного тарифа (запросы/токены в минуту и в сутки), размер контекста, качество на русском, нужна ли банковская карта или телефон, доступность из России, используются ли запросы для обучения
- [ ] Есть раздел по локальному запуску LLM на Mac с 16 ГБ (Ollama / LM Studio / llama.cpp, модели 7–14B в квантизации) с оценкой занимаемой памяти и скорости и честным указанием просадки качества на русском относительно облачных моделей
- [ ] Показан расчёт: транскрипт лекции длительностью 1.5 часа ≈ столько-то слов и токенов (виден сам расчёт, а не только результат), и вывод по каждому кандидату шортлиста — влезает ли транскрипт целиком в контекст
- [ ] Описана стратегия обработки длинного транскрипта при невлезании: чанкинг по смысловым блокам с сохранением таймкодов, map-reduce, сборка финального саммари; указано, где теряется качество
- [ ] Приведены готовые промпты на русском для четырёх задач: краткое саммари, тезисы/план лекции, глоссарий терминов с определениями, вопросы для самопроверки; для каждого указан ожидаемый формат вывода в Markdown
- [ ] Есть раздел «Приватность»: какие данные уходят в облако (текст транскрипта, не видео) и что делать, если запись нельзя отдавать наружу
- [ ] Итоговая рекомендация: один основной вариант и один fallback, с обоснованием именно под нулевой бюджет и доступность из России
- [ ] Все цифры по лимитам снабжены ссылкой на страницу тарифов и датой проверки 2026-10-03; быстро устаревающие значения помечены
- [ ] Документ на русском языке

## Контекст

Решения владельца: бюджет 0 — только бесплатные тарифы и локальные модели; платные тарифы допустимо упомянуть одной строкой для контекста, но не рекомендовать. Железо: MacBook Apple Silicon M5, 16 ГБ унифицированной памяти — оценки локальных LLM только под это. Язык документа — русский. Владелец находится в России: доступность сервиса из РФ и необходимость карты/телефона при регистрации — существенные критерии. Распознавание речи делается локально, но для саммари владелец согласен отдавать текст в облако, поэтому раздел про приватность нужен, но запретительным быть не должен.

Саммари не входит в MVP (целевой MVP — текст + SRT/VTT), это следующий этап, но ресерч по нему владелец просил сделать сейчас, чтобы заранее знать, на что опираться. Поэтому документ — разведка и готовые промпты, а не рабочий код.

Запрещено скачивать модели и веса. Поэтому раздел про локальные LLM — расчёты и оценки по публичным данным, без запуска. Разрешено ставить python-пакеты, если нужно для подсчёта токенов (например tiktoken), но запросов к платным API не делать и ключи никуда не вписывать.

Если доступен веб-поиск — пользуйся им и ставь ссылки на страницы тарифов; если недоступен, опирайся на внутренние знания и помечай каждое число как «требует проверки, лимиты меняются часто».

Полная карта документов проекта (их создают другие задачи, не трогай): README.md, .gitignore, docs/analysis/example-recordings.md, docs/research/asr-models.md, docs/research/benchmark-plan.md, docs/plan.md, docs/decisions/delivery-form.md, scripts/**. Твой файл один — docs/research/summarization-apis.md.

## Не входит в задачу

Не писать код обращения к API, не регистрировать аккаунты и не получать ключи, не делать реальные запросы к LLM, не скачивать модели, не обозревать ASR-модели (это другая задача), не трогать никакие файлы кроме docs/research/summarization-apis.md.
